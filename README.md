# Scroll Drive: GSAP Scroll-Based Hero Animation

A premium-looking hero section built with Vite, React, Tailwind CSS, and GSAP. As the user scrolls, a futuristic car drives across the screen while passing by animated statistics. 

## Features
- **GSAP Animations**: Smooth intro sequence with staggered text reveal and count-up numbers.
- **ScrollTrigger Integration**: Pinning and scrubbing to control the car's movement based on scroll position.
- **Smooth Scrolling**: Implemented using Lenis for a buttery-smooth scrolling experience.
- **Parallax Background**: Depth effect with moving abstract city layers and a dashed road line.
- **Accessibility**: Respects `prefers-reduced-motion` settings by skipping animations and presenting the final state.
- **Responsive Design**: GSAP `matchMedia` is used to adjust animation scale and distances for mobile vs desktop.

## Tech Stack
- **Vite + React (JavaScript)**
- **Tailwind CSS**
- **GSAP (ScrollTrigger)**
- **Lenis**
